# v0.4.11 — 浮窗可收成下拉菜单（少抢鼠标），回话与「转 @码」合并成两行

这一版把浮窗（常驻译文悬浮框）做了一轮"游戏里更好用"的改造：顶栏可以收成一个 ⋯ 菜单、
可点击面积大幅变小；浮窗里回话时可以直接带上游戏内 `@码`，一次「翻译」出两行。

## 下载

| 文件 | 说明 |
| --- | --- |
| `SCTranslator-v0.4.11-win64.zip` | 解压到任意目录 → 双击 `SCTranslator.exe` |

## 新增

| 功能 | 说明 |
| --- | --- |
| **浮窗顶栏两种样式：平铺 ⇄ 下拉菜单** | 设置「译文浮窗」里的「顶栏收进下拉菜单」勾上后，顶栏的截图翻译/嘴臭/穿透/固定四个按钮收进一个 **⋯** 菜单，只留 ⋯ 与 ✕。游戏里鼠标划过浮窗时更不容易把光标"引"出来（**默认仍是平铺**，老用户升级后界面不变） |
| **浮窗回话合并「中文码行」** | 浮窗里输入中文点「翻译」：**开**了码行 → 出两行 ``[zh] @码`` + ``[en] 译文``（中文玩家看得懂码、外文玩家看译文）；**关**着 → 只出外文。开关就是浮窗顶栏的 **「@码：开/关」** 按钮，或下拉菜单里的「开启/关闭中文码行」——不用回主窗口，也不用改设置 |
| **「显示浮窗」按钮移回主界面** | 在浮窗里点过 ✕ 之后，主界面「按需截图翻译」卡片上和「立即截图翻译 / 重新框选」同排就能把它叫回来（此前藏在设置对话框里） |

## 改进

| # | 事项 | 说明 |
| --- | --- | --- |
| 1 | **回话两行格式全项目统一** | 主窗口游戏聊天码卡片、主窗口回话卡片、浮窗回话现在都走同一处格式定义（`[zh] @码` 在前、`[en] 译文` 在后），不会再出现两处顺序不一致 |
| 2 | **失败要退化，不许静默** | 浮窗开了码行但本机没有汉化码表（或输入里没有可编码的中文）时，**自动退回只发译文**，并在浮窗提示条里说明原因 |
| 3 | **避免死开关** | 开着「中文码行」但浮窗回话输入条是关的 → 打开码行时自动把回话条打开（并写入设置、同步主窗口勾选），不会出现"开关打开了却没地方输入" |

## 升级提示

- **默认什么都不会变**：顶栏仍是平铺、码行仍是关（只出外文）。要用新东西：设置里勾「顶栏收进下拉菜单」；浮窗上点「@码」。
- **码行开关是临时的**：它不写进设置，重启程序回到"关"。要一直带码行，每次启动点一下即可。
- **顺序与主窗口一致**：都是 `[zh] @码` 在前、`[en] 译文` 在后。
- 已知小瑕疵（未修，等你是否要）：浮窗里的滚动条手柄用的是不透明配色，把不透明度调很低时它是一条深色实心条（其余部分正常淡出）。
- **游戏内热键仍然可能不响应**（老问题，本轮没动）：真机实测本程序注册成功、非前台/最小化/隐藏都能收到热键消息，差别只在"游戏在前台"。先用鼠标点浮窗上的 **🎯 翻译** 顶上；也可以试**以管理员身份运行**本程序并把结果告诉我。
- 设置与数据仍在程序目录下的 `data\`，**覆盖升级不会丢设置**。
