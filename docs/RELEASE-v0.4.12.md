# v0.4.12 — @码识别真正可用 + 五路并行修复评审发现的 52 项问题

这一版先把上一版「OCR 识别出 `@xx` 字符码后先转汉字再送翻译」的**致命缺陷**修掉

## 修复（严重）

| # | 问题 | 根因 | 修复 |
| --- | --- | --- | --- |
| 1 | **@码解码对数字码完全失效** | OCR 分词的字母-数字边界规则把 `@E8` 拆成 `@E 8`，发生在解码之前；社区锚点 `你好吗 = [zh] @IH@E8@AP` 恰好含数字码 ⇒ 解成 `你@E 8吗` | 补空格时用 `\x00` 占位保护 `@[0-9A-Za-z]+` token，处理完再还原；真机端到端验证 `你好吗` 完整解码 |
| 2 | **半截码 / 邮箱被误解码** | `@IH@E` 被解成 `你@E`（原文+译文混合乱码）；`a@IH.com` 被解成 `a你.com`（真实码表两位码空间全覆盖） | 解码前做 `@` 上下文守卫：半截码、域名邮箱、字母紧贴 `@` 的上下文整条返回原文 |
| 3 | **编号批译静默错行** | 以模型回显的序号建键，模型漏答/重排号时第 2 行拿到第 3 行译文 | 严格校验编号集合 1..N 与条数，不一致整批回退逐条翻译 |
| 4 | **日文/中日混排被当中文原文透传** | `_cjk_ratio>0.55` 只数汉字比例，汉字密集日文不走 API | 透传前排除假名/谚文，仅纯中文行才免 API |
| 5 | **设置文件可能半截写坏、用户配置静默全丢** | `settings.save()` 原地截断写、无锁；崩溃留半截 JSON，load 吞异常回退默认值 | 加锁 + 临时文件 + `os.replace` 原子替换 |
| 6 | **切语言 / 关窗后后台回调打到已销毁控件** | 主线程 done 回调无关闭守卫，旧窗 deleteLater 后仍被写入 | 每个 done 入口加 `_shutting_down` 守卫；AppController 加 epoch 丢弃过期回调 |
| 7 | **热键注销时序** | `install_hotkeys()` 先注销旧服务再取新 hwnd，窗口销毁中抛异常时全局热键全失效 | 先校验新 hwnd 再注销旧服务，失败保留旧注册 |
| 8 | **浮窗滚动条手柄在低不透明度下是深色实心条** | 应用级 stylesheet 给 `QScrollBar::handle` 不透明色，浮窗样式没覆盖 | 浮窗内滚动条手柄改带 alpha 的规则（坑点 #8 同类已知项） |

## 改进

| 功能 | 说明 |
| --- | --- |
| **API Key 存储更稳** | Windows 上 DPAPI 不可用时不再悄悄写明文 Key，改为显式 opt-in；DPAPI 用 `use_last_error` 显式签名，失败日志可定位 |
| **缓存更准确** | 缓存键纳入目标语言（同原文翻 en/ja 不再串味）；缓存 flush 写入纳入锁 + 唯一临时文件，避免并发损坏 |
| **术语表更严谨** | 词边界覆盖数字/下划线（`Pyro2`/`Cpt_Pyro` 不再误替换）；异常前缀下不再误译玩家名；全局状态改 copy-on-write + 锁 |
| **更少重复开销** | Session 改 thread-local；`_no_thinking` 提升进程级状态，新建客户端不再重复付 400+ 重试 |
| **启动自检更诚实** | `--doctor` 走最小只读路径（无迁移/bootstrap 副作用）；损坏的 settings.json 直接判 FAIL，不再被 load 吞异常误报 PASS |
| **发布脚本更可靠** | `build.bat` 校验产物并生成发布 ZIP；`publish.bat` 在 push 前检查分支/洁净工作区/发行材料 |
| **界面三语更完整** | 新增 15 个三语键，主窗口/浮窗/热键控件里的硬编码中文全部走 i18n（共 274 键） |

## 升级提示

- **升级后首次截图翻译里的玩家 @码会直接显示为中文**（此前是乱码或原样 `@xx`），译文里也会读到正确语义。
- **码行开关仍是临时的**（不写设置，重启回关），位置不变：浮窗顶栏 `@码` 按钮或 ⋯ 菜单项。
- **API Key 加密兜底变更**：Windows 上若 DPAPI 不可用，`save_api_key()` 会返回 False 且不保存明文；需要明文模式须显式设置环境变量 `SC_TRANSLATOR_ALLOW_PLAINTEXT_KEY=1`。
- **缓存键变更**：升级后首轮翻译会重新请求（旧缓存自然不命中），属正常。
- 已知边界：真·全屏游戏内的热键响应仍未实测（老问题）；`tools/复核-截图翻译端到端.py` 直跑需设 `PYTHONPATH`（已用环境变量绕过，未改脚本）。
- 设置与数据仍在程序目录 `data\`，**覆盖升级不会丢设置**。
