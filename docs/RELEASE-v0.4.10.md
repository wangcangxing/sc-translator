# v0.4.10 — 修完 3 个用户反馈（回话区黑块 / 粘连分词 / 玩家名被翻译），并加上浮窗一键翻译与 OCR 启动预热

这一版来自真机实测反馈：修了 3 个问题（其中一个的真凶是我们自己的术语表预替换），
并按需求加了「浮窗一键翻译」与「启动预热 OCR」，另外把"一句话被折行拆成几行分别翻译"也一并修掉。

## 修复（用户反馈）

| # | 反馈 | 根因（实测确认） | 修复 |
| --- | --- | --- | --- |
| 1 | 浮窗**调低不透明度后，回话区是一块实心黑** | 应用级样式表里的 `QWidget { background-color: #10141b }` 被浮窗内部控件继承，回话区的问答卡片又自带不透明底色 ⇒ 其余部分透明了，这一块仍是黑的 | 浮窗子树在 `theme.overlay_style` 里统一压透明，卡片改用**带 alpha** 的底色；不再在子控件上写死不透明样式（这样它也随不透明度一起淡出） |
| 2 | **部分识别文字分词错误**（`takedisable`、`whichgivesyou` 拼在一块；`interdict or s`、`capac at or s` 被切错） | 粘连分词阈值原为 14 个字母，11~13 字符的粘连词从不切分；而更长的粘连串用词典切分时会把 `interdictors` 切成 `interdict or s` | 阈值 **14 → 8**；新增**单字母碎片否决**（`a`/`i` 除外）——切出无意义碎片就整段保持原样，**宁可显示粘连也不显示切错的词** |
| 3 | **玩家名被翻译**（`[全局]Cpt_Andromeda:` → `[全局]Cpt_仙女座:`） | **不是模型的问题**：本机术语表里确有 `andromeda = 仙女座`，于是送模型之前名字就已经变成中文，提示词里"保持前缀"无从生效 | 术语表替换（预替换 + 译文兜底替换）改为**只作用于冒号后的正文**；`[频道] 玩家名:` 前缀一律不动 |
| 4 | 一句话被折行拆成几行**分别翻译**（`gateway` 单独译成「网关」、句尾 `rien` 单独成行） | 游戏聊天的折行由 OCR 逐行返回，而代码是逐行送翻译 | 翻译前先把"无消息头的行"并回**上一条聊天消息**（只在聊天消息内部合并，选中 UI/任务文本区域时行为不变） |

## 新增

| 功能 | 说明 |
| --- | --- |
| **浮窗一键「🎯 翻译」按钮** | 固定态在标题栏，**穿透态在顶部常驻小条**上（默认就是穿透态，所以两种状态都点得到）。游戏里全局热键不响应时，用鼠标点它即可触发一次截图翻译 |
| **点完把焦点还给游戏** | 点浮窗按钮会让本程序接管前台、游戏收不到键盘；现在触发后**立刻把前台还给点击前的那个窗口**（300ms 轮询记住它，2 秒内有效）。还没框选过区域时会进全屏框选，那一步需要焦点，故不归还 |
| **启动预热 OCR** | 启动约 3 秒后在后台把 OCR 模型加载好：第一次按热键不再背模型冷启动（实测日志里第一次截图翻译的 OCR 耗时 **14625 ms**，预热后首次即为 0.3~0.5 s 量级）。热键停用、或开了「模型直接读图」时不预热 |

## 实测数字

| 项目 | 结果 |
| --- | --- |
| OCR 预热的常驻内存（整进程树，工作集） | 不预热 **163.2 MB** → 预热 **237.7 MB**，即 **+约 75 MB**（提交大小另计 +673 MB，那是 onnxruntime 预留的 arena，**不是**实体内存） |
| OCR 预热耗时 | 模型加载 **约 0.4~0.5 s**（后台线程，不挡界面） |
| 折叠消息合并 | 真机合成图：一条被折成 3 行的消息 → 合并为 **1 条**再送译 |
| 玩家名保护 | 真实术语表对照：旧 `[全局]Cpt_仙女座: …` → 新 `[全局]Cpt_Andromeda: …`（正文里的 `pyro` 仍照常替换为「派罗星系」） |
| 回话区不透明度 | 真机截图对比：修复前是实心黑块，修复后与其余部分一起淡出 |

## 升级提示

- **预热会让常驻内存多约 75 MB**（换来第一次按热键不再等十几秒）。不想付这个代价：设置里关掉「启用热键」，或改用「模型直接读图」——这两种情况都不会预热。
- 浮窗按钮在两处：固定态标题栏、穿透态顶部小条。没用过的话先在浮窗上找 **🎯 翻译**。
- **游戏内热键仍然可能不响应**（本轮只给了鼠标替代入口）：真机实测本程序注册本身是成功的，且非前台/最小化/隐藏三种情况都能收到热键消息；剩下的差异只在"游戏前台"。你可以先试**以管理员身份运行**本程序——若有效请反馈，我再据此改。
- 设置与数据仍在程序目录下的 `data\`，**覆盖升级不会丢设置**。
